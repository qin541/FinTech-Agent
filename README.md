# 📈 FinTech-Agent: 面向个人投资者的智能财报分析助手

## 💡 项目背景与痛点
对于非专业的个人投资者而言，阅读动辄上百页的 A 股财务报告存在极高的门槛。传统的搜索方式难以快速提取关键财务指标，且现有通用大模型在阅读长文档时容易产生“数据幻觉”（张冠李戴）。本项目旨在通过大语言模型（LLM）与 RAG 技术，打造一个懂金融、防幻觉的专属财报分析助手。

## 🚀 核心功能
- 财报深度解析：支持上传 PDF 格式的财报，通过 RAG 技术实现基于文档内容的精准问答。
- 防幻觉机制：通过设计结构化 Prompt 约束模型行为，确保数据来源可靠，不提供投资建议。
- 极简交互界面**：基于 Streamlit 搭建 Web 端交互界面，降低用户使用门槛。

## 🛠️ 技术栈与架构
- 前端交互：Streamlit (Python)
- 后端大脑 (Agent)：Dify (Workflow 编排与知识库管理)
- 底层模型：DeepSeek-V3 (或你用的模型)

## 🧠 我的贡献与产品决策 (核心重点)
1. 架构选型与 Vibe Coding 实践：
   作为产品方向的候选人，我独立负责了从需求调研到 Demo 落地的全流程。采用 Vibe Coding 模式，借助 AI 编程工具（Cursor / 网页端 AI）快速生成 Streamlit 代码，并在 1 天内完成了云端部署，验证了产品可行性。
2. 上下文工程与 RAG 参数调优：
   针对财报中“表格密集”导致数据断裂的痛点，我在 Dify 知识库中进行了控制变量实验。通过对比不同 Chunk Size（切分粒度）与 Overlap（重叠度）下的检索表现，总结出针对金融长文档的最佳参数配置。
3. 评测体系建设：
   构建了包含 20 个典型投资者问题的测试集，对系统输出进行人工标注。通过分析 Badcase（翻车案例），持续优化 Prompt 的指令与防幻觉兜底逻辑。

## 📊 实验结论与反思 (待补充 - 等你做完实验再补)
- 发现：使用默认切分时，模型经常将 2022 年的净利润误判为 2023 年。
- 优化：将 Chunk Size 调大并优化 Prompt 后，数据提取准确率显著提升。
- 局限：目前仅支持纯文本交互，未来计划引入语音交互，探索在“可穿戴设备”场景下的应用（呼应岗位JD）。
